🎨 Customization Tips
Change brand color: Edit brand-500/brand-600 in the Tailwind config (try #0ea5e9 for blue, #059669 for green)
Swap logo: Replace the <h1> block with an <img> for a real logo
Add dark mode: Append dark: variants — the structure already supports it
Real backend: Replace static cards with a loop from your CMS (WordPress/Laravel/Next.js)
The theme is production-ready for conversion into WordPress, Next.js, or Laravel Blade — all sections are cleanly separated and semantically structured.
